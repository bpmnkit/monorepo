# Code of Conduct

## Our standard

This project adopts the [Contributor Covenant, version 2.1][covenant] as its code of conduct.
The canonical text lives at that link and governs; it is referenced rather than copied so that
this file cannot drift from it.

In short: everyone taking part — in issues, pull requests, discussions and any other project
space — is expected to behave in a way that makes the project welcoming to people regardless of
age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity
and expression, level of experience, education, socio-economic status, nationality, personal
appearance, race, religion, or sexual identity and orientation.

Harassment, insults, personal or political attacks, publishing others' private information, and
unwelcome sexual attention are not acceptable here.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

This applies in every project space — the repository, its issues and pull requests, and any
place where someone is representing the project in public.

## Reporting

Report unacceptable behaviour privately to the maintainers through GitHub's
[private vulnerability reporting form](https://github.com/bpmnkit/monorepo/security/advisories/new),
which is the only private channel this project currently has. Mark the report clearly as a code
of conduct matter rather than a security issue.

If the report concerns a maintainer, or you would rather not use a project channel at all, use
GitHub's own [report abuse](https://github.com/contact/report-abuse) route.

All reports are reviewed and investigated, and the reporter's identity is kept confidential.

## Enforcement

Maintainers are responsible for clarifying this standard and may edit, remove or reject
comments, commits, code, issues and other contributions that do not align with it, explaining
their reasons where appropriate.

The Contributor Covenant's [enforcement guidelines][covenant] — correction, warning, temporary
ban, permanent ban — are the ladder used, chosen in proportion to the behaviour.
