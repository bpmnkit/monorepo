# Installation — Runtime Requirements

| Runtime | Minimum Version |
|---|---|
| Node.js | 20 LTS |
| Deno | 1.40+ |
| Bun | 1.0+ |
| Browsers | ES2022 (Chrome 94, Firefox 93, Safari 15.4) |

All packages are **ESM-only** (`"type": "module"`). CommonJS is not supported.
