# What is FEEL?

Learn more about using Friendly Enough Expression Language (FEEL) in Camunda. FEEL is a part of the DMN specification of the Object Management Group (OMG).

**Friendly Enough Expression Language (FEEL)** is designed to write [expressions](https://docs.camunda.io/docs/next/reference/glossary#feel-expression) in a way that is easily understood by both business professionals and developers. In Camunda, FEEL is used to define expressions in the context of [BPMN diagrams](https://docs.camunda.io/docs/next/components/modeler/bpmn/bpmn), [DMN diagrams](https://docs.camunda.io/docs/next/components/modeler/dmn/dmn), and [Forms](https://docs.camunda.io/docs/next/components/modeler/forms/camunda-forms-reference). FEEL is specified in
the [DMN specification](https://www.omg.org/spec/DMN/) of the Object Management Group (OMG).
