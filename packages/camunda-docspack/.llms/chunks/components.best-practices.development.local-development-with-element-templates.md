# Local development with element templates and Camunda 8 Run

Learn how to use Camunda 8 Run with element templates in your local development environment.

When working with [element templates](https://docs.camunda.io/docs/next/components/concepts/element-templates) in your local development environment using [Camunda 8 Run with Docker Compose](https://docs.camunda.io/docs/next/self-managed/quickstart/developer-quickstart/c8run), ensure all dependencies are provisioned before you start.

This guide explains how to set up element templates in your local environment.


## Prerequisites

- [Camunda 8 Run](https://docs.camunda.io/docs/next/self-managed/quickstart/developer-quickstart/c8run) installed on your local machine.
- Basic knowledge of [element templates with dependencies](https://docs.camunda.io/docs/next/components/modeler/element-templates/element-template-with-dependencies).
- Familiarity with [custom connectors](https://docs.camunda.io/docs/next/components/connectors/manage-connector-templates).
