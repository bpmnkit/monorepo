# BPMN in Modeler — Start modeling

![Start Modeling](./assets/quickstart-2.png)

Web and Desktop Modeler both offer a similar core BPMN 2.0 Modeling experience:

- Add BPMN elements from the palette on the left side of the page by dragging and dropping them onto the diagram canvas.
- Change the type of element in place by clicking on an element to reveal the context menu. Then, select the **Change element** menu icon to change the type of element to a [service task](https://docs.camunda.io/docs/next/components/modeler/bpmn/service-tasks/service-tasks) or [user task](https://docs.camunda.io/docs/next/components/modeler/bpmn/user-tasks/user-tasks), for example.


## Creating BPMN elements

Using BPMN in Modeler, you can create more BPMN 2.0 elements like task types and event definitions.

For example, [service tasks](https://docs.camunda.io/docs/next/components/modeler/bpmn/service-tasks/service-tasks) within Camunda 8 require you to set a task type and implement [job workers](https://docs.camunda.io/docs/next/components/concepts/job-workers) to perform a particular task in a process.

Review [the BPMN 2.0 coverage documentation](https://docs.camunda.io/docs/next/components/modeler/bpmn/bpmn-coverage) for a complete list of BPMN elements supported by our modeling tools.

Additionally, visit [creating readable process models](https://docs.camunda.io/docs/next/components/best-practices/modeling/creating-readable-process-models) for general guidelines on modeling with BPMN.
