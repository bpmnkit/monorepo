# Modeling with BPMN — Creating BPMN elements

Using BPMN in Hub or Desktop Modeler, you can create more BPMN 2.0 elements like task types and event definitions.

For example, [service tasks](https://docs.camunda.io/docs/next/components/modeler/bpmn/service-tasks/service-tasks) within Camunda 8 require you to set a task type and implement [job workers](https://docs.camunda.io/docs/next/components/concepts/job-workers) to perform a particular task in a process.

Review [the BPMN 2.0 coverage documentation](https://docs.camunda.io/docs/next/components/modeler/bpmn/bpmn-coverage) for a complete list of BPMN elements supported by our modeling tools.

Additionally, visit [creating readable process models](https://docs.camunda.io/docs/next/components/best-practices/modeling/creating-readable-process-models) for general guidelines on modeling with BPMN.
