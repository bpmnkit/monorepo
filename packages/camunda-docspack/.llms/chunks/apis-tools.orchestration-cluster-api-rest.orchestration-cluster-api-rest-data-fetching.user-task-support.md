# Data fetching — User task support

The Orchestration Cluster REST API only supports Camunda user tasks (previously referred to as [Zeebe user tasks](https://docs.camunda.io/docs/next/apis-tools/migration-manuals/migrate-to-camunda-user-tasks), which may still appear as `zeebe:userTask` in your XML content).


## Search requests

Search requests consist of the components for **filter**, **sort**, and **page**.
