# Introduction

Everything begins with [data types](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types). Read on this subject first to have a better
understanding of the other content like [expressions](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-expressions-introduction) and [built-in functions](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-functions).

If you're writing an expression for an input entry of a decision table, visit our documentation on [unary-tests](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-unary-tests).

Otherwise, have a look at the more general section
about [expressions](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-expressions-introduction).

Looking for a function to call? Visit our documentation on [built-in functions](https://docs.camunda.io/docs/next/components/modeler/feel/builtin-functions/feel-built-in-functions-introduction).
