# Service integration patterns with BPMN — Integrating services with BPMN tasks — Service task

The [service task](https://docs.camunda.io/docs/next/components/modeler/bpmn/service-tasks/service-tasks) is the typical element to implement synchronous request/response calls, such as REST, gRPC or SOAP. You should **always use service tasks for synchronous request/response**.
