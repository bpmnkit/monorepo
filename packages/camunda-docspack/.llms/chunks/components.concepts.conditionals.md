# Conditionals

Learn how conditional events let processes react automatically to data changes.

Conditional events allow a process to react automatically when variables match a condition. Instead of waiting for a message or signal, the engine evaluates a FEEL expression over process variables and triggers the event when the expression becomes `true`.

Conditional events are similar to [messages](https://docs.camunda.io/docs/next/components/concepts/messages) and [signals](https://docs.camunda.io/docs/next/components/concepts/signals), but they are triggered by variable changes instead of external correlation or broadcast.

For details on which BPMN event types support conditionals and how to model them, see the [conditional events modeling guide](https://docs.camunda.io/docs/next/components/modeler/bpmn/conditional-events/conditional-events).
