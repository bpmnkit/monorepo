# Overview

This document outlines an overview of supported elements.

**Subprocesses** are element containers that allow defining common functionality. For example, you can attach an event to a subprocess's border.

When the event is triggered, the subprocess is interrupted, regardless which of its elements is currently active.

Currently supported elements:

- [Embedded subprocess](https://docs.camunda.io/docs/next/components/modeler/bpmn/embedded-subprocesses/embedded-subprocesses)
- [Call activities](https://docs.camunda.io/docs/next/components/modeler/bpmn/call-activities/call-activities)
- [Event subprocess](https://docs.camunda.io/docs/next/components/modeler/bpmn/event-subprocesses/event-subprocesses)
- [Ad-hoc sub-process](https://docs.camunda.io/docs/next/components/modeler/bpmn/ad-hoc-subprocesses/ad-hoc-subprocesses)
