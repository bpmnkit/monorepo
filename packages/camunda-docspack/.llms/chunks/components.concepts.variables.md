# Variables

Variables are part of process instances and represent their data. Leverage the scope of variables and customize how they are merged into process instances.

[Variables](https://docs.camunda.io/docs/next/reference/glossary#variable) are part of a [process instance](https://docs.camunda.io/docs/next/reference/glossary#process-instance) and represent the data of the instance.

A variable has a name and a JSON value. The visibility of a variable is defined by its variable scope.

When [automating a process using BPMN](https://docs.camunda.io/docs/next/components/modeler/bpmn/automating-a-process-using-bpmn), [orchestrating human tasks](https://docs.camunda.io/docs/next/guides/getting-started-orchestrate-human-tasks), or implementing [agentic orchestration](https://docs.camunda.io/docs/next/components/agentic-orchestration/agentic-orchestration-overview), you can leverage the scope of these variables and customize how variables are merged into the process instance.
